# 用药管家 🏠💊

一款基于微信小程序的**家庭用药管理工具**，帮助你和家人轻松管理药品，按时服药，远离过期风险。

## 功能概览

### 👨‍👩‍👧‍👦 家庭成员管理
- **添加成员** — 录入家庭成员信息，支持头像、姓名、关系（本人/父亲/母亲/配偶/子女/其他）和备注。
- **成员列表** — 首页集中展示所有家庭成员及其关联的药瓶数量。
- **删除成员** — 在成员详情页可一键移除不再需要的成员。

### 💊 药瓶管理
- **为成员添加药瓶** — 记录每瓶药的名称、剂量、服药时间安排、有效期和备注。
- **编辑与删除** — 支持随时修改或删除已有药瓶。
- **有效期追踪** — 自动计算每个药瓶的剩余有效天数，区分**已过期**和**临期（30天内）** 状态。

### ⏰ 服药提醒
- **提醒列表** — 汇总所有设置了服药时间的药瓶，按成员展示。
- **服药确认** — 点击「是否服药」标记已完成服药，卡片变为确认态。
- **状态重置** — 支持取消确认，方便重复提醒场景。
- **跨天自动刷新** — 每天自动重置服药确认状态，无需手动操作。
- **终止时间设定** — 可为每个提醒设置服药终止时间，卡片颜色根据剩余时间自动变化：
  - 🔵 **蓝色** — 距离终止时间超过 1 小时
  - 🟡 **黄色** — 距离终止时间不足 1 小时
  - 🔴 **红色** — 已超过终止时间

### ⚠️ 过期预警
- **临期提醒** — 距过期 ≤ 30 天的药品自动列入临期预警。
- **过期警示** — 已过期的药品高亮显示并标注"已过期"。
- **优先级排序** — 越临近过期的药品越靠前展示。

### 🏪 附近药房
- 快捷入口，方便查找附近药房（预留功能）。

## 快速开始

### 环境要求

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（最新稳定版）
- 微信小程序 AppID（可用测试号）

### 运行步骤

1. **克隆项目**
   ```bash
   git clone <repo-url>
   ```

2. **打开微信开发者工具**，选择「导入项目」，填写：
   - 项目目录：选择 `jiatingyongyao` 文件夹
   - AppID：`wxff9d22936ab6e769` 或你自己的测试号

3. **编译运行**，即可在模拟器中预览。

> 💡 项目使用微信本地存储，所有数据保存在用户设备上，无需额外部署后端服务。

## 使用指南

| 操作 | 路径 |
|------|------|
| 查看家庭成员 | 首页 |

## 数据说明

- 所有数据通过 `wx.setStorageSync` 存储在用户设备本地。
- 数据结构主要包含：
  - **members** — 成员数组，每个成员包含 `id`、`name`、`avatar`、`relation`、`note`、`bottles`。
  - **bottles** — 药瓶数组（嵌套在 member 下），包含 `id`、`medicineName`、`dosage`、`schedule`、`expiresDate`、`note`、`confirm`、`endTime`。
  - **lastRecordDate** — 最近一次访问的日期，用于跨天自动刷新。
